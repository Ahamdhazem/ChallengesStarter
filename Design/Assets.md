# Supplied assets — 8-hour scope

Only the artwork needed by the attached list/details designs and three Poppins weights is included. Source: the existing SalesApp assets. No third-party image downloads or remote links are required to open the starter.

| Area | Asset |
| --- | --- |
| Back / chevron | `arrow_left`, `arrow_right_black64` |
| Search / filter | `black_search_icon`, `primary_settings_icon` |
| Dates / expiry | `clock_green500_icon`, `clock_icon_black64`, `expiry_day_info_icon` |
| Header | `challenge_details_image`, `briefcase_icon` |
| Reward type fallbacks | `spin_type_icon`, `box_open_icon`, `coins_icon`, `badge_placeholder_icon`, `money_black57_icon`, `reward_placeholder_icon` |
| Optional product examples | `e-voucher`, `phone_card_icon` (do not infer from translated product names) |
| Image fallbacks | `reward_placeholder_icon`, `challange_placeholder_icon` |
| Completed mark | `black_check_icon`, `check_icon_success500` |

Required reward artwork is only reward_placeholder_icon for every row. Remote images, type-specific reward icons and completion glyphs are optional; the extra bundled assets are reference material. Status and text still come from the model.

Fonts: Poppins Regular, Medium and SemiBold, registered in Info.plist. Screen title 16pt Medium; card titles/reward names 12–14pt Medium; secondary text 10–12pt Regular. The editable XIBs are blank so the trainee implements the designs.

The named color assets provide the palette. The list/details screenshots are the design reference; `ChallengeFlow.svg` is a portable summary for the handoff.

See `Documentation/FieldMapping.md` for the reduced UI fields and Leave state rules.
